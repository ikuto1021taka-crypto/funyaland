# 🧸 ふにゃふにゃランド

ふにゃふにゃのぬいぐるみになって遊ぶ、おバカな3Dゲームです。

**▶ 遊ぶ：https://ikuto1021taka-crypto.github.io/funyaland/**

アカウント登録なし・無料。パソコンでもスマホでも、ブラウザで開くだけで遊べます。

## おはなし
ようちえんにきふされた、ふにゃふにゃのぬいぐるみ。
みんながねむった夜、ぬいぐるみは立ち上がって、ぬいぐるみたちの町「ふにゃふにゃランド」へ！

## 遊べること
- なぐる・つかんでぶん投げる・車にひかれてぺしゃんこ！ ふにゃふにゃの体で大あばれ
- キャラメイクで、自分だけのぬいぐるみの柄をかける
- お店・ホテル・旅館・温泉・キャンプ場・遊園地がある町を自由に探検
- ジェットコースター（一回転つき）・観覧車・つり・ガチャ
- オセロ・五目ならべ・トランプ（ババ抜き・神経衰弱・ブラックジャック）
- 朝と夜・天気・モンスターやわるもの集団のイベント
- 自分の島を作って、兵士をやとって軍隊を作れる
- 服・くつ・ぼうしで着せかえ

## 友だちと
- 部屋コード、またはフレンドならコードなしで部屋に入れる
- チャット・ボードゲームやトランプのネット対戦
- 部屋には40人まで入れる（人数が多いと重くなることがあります。数人〜10人くらいがおすすめ）

## そうさ
- パソコン：WASD で移動、スペースでジャンプ、クリックでパンチ、右クリックでつかむ、E で調べる
- スマホ：画面のスティックとボタン（横向きがおすすめ）
- ゲームの中の「📖 あそびかた」（H キー）でくわしく見られます
